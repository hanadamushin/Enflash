# Enflash

English と flash を組み合わせた名前の、英文チャンクリーダーです。英語のPDF、画像、テキストから文章を読み込み、チャンクを中央に順次表示します。初回はこのアプリ用に書いたオリジナル例文が表示されます。文章を直接貼り付けることもできます。サンプル例文は自由に再利用できます。

## 起動・公開

`index.html`, `style.css`, `app.js` をリポジトリのルートに置き、GitHub の **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)** を選びます。公開後のURLは `https://<username>.github.io/<repository>/` です。ローカルでは `python3 -m http.server 8000` を実行して `http://localhost:8000/` を開けます。

## 使い方

PDF・画像・TXTを選ぶか、英文を貼り付けて「再生」を押します。表示単位、速度、再生位置を変更できます。Spaceで再生と停止、左右矢印でチャンク移動。再生中に別のタブへ移ると一時停止します。

## 仕様と限界

- PDF.js がPDFのテキストを抽出します。文字の少ないページは画像化し、Tesseract.js で英語OCRを行います。画像もOCRで処理します。ライブラリと英語学習データをCDNから読み込むので初回使用には通信が必要です。
- ファイルの本文はアプリのサーバーに送信しません。処理はブラウザ内で行い、タブを閉じると内容は消えます。GitHub Pagesにアップロードしたファイルを公開する機能はありません。
- 2段組み、脚注、複雑なレイアウト、画像の品質によって文字順や認識精度が崩れることがあります。抽出後のテキストを確認してください。
- チャンク分割は簡易的な語数・句読点の規則です。意味構造を厳密に解析しません。WPMは文章の単語数に基づく目安で、理解度を保証しません。
- 音声や翻訳、理解度の自動採点はありません。読後の要約欄で自分の理解を確認できます。

PDF.js (Apache-2.0) と Tesseract.js (Apache-2.0) をCDNから利用します。
